# LEIbmec — Site Oficial

Site da Liga de Empreendedorismo Ibmec SP.

## Como rodar

### Desenvolvimento
npm install
npm run dev

Acesse: http://localhost:3000

### Produção
npm run build
npm start

Acesse: http://localhost:8080

## Rotas
- `/` — Página principal
- `/processo-seletivo` — Processo seletivo detalhado
- `/instagram` — Redirect para Instagram
- `/inscricao` — Redirect para formulário de inscrição
- `/api/health` — Health check

## Estrutura
- `src/components/` — Componentes de UI
- `src/pages/` — Páginas do site
- `src/animations/` — Animações JavaScript
- `src/styles/` — Arquivos CSS
- `server/` — Backend Express (para produção)
